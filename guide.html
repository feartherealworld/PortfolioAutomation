How It Works

The bot runs in the cloud on Modal (free tier). Every few minutes it:

  1. Reads the latest signal from Prof Adam's Portfolio Signals channel via TRW's API
  2. Parses the allocation percentages (e.g. 80% ETH, 14.3% HYPE, 5.7% PAXG)
  3. Compares to your current Hyperliquid positions
  4. Rebalances if the signal has changed — using 1x leverage perps
  5. Sends you a Slack notification with execution details and price deviation from bar close

Step 1 — Get Your TRW Session Token

The bot needs to read messages from the signal channel. TRW uses a session token for authentication.

1

Open TRW in Chrome or Brave

Navigate to Prof Adam's Portfolio Signals channel.

2

Open DevTools

Press F12 to open DevTools. Click the Network tab, then click Fetch/XHR.

3

Reload and find the token

Reload the page (F5). Click any request in the list. In the Headers tab, scroll to Request Headers and find x-session-token. Copy the entire value.

⚠️ Never share your session token. Copy it directly into the manager GUI (python manage.py). Do not paste it into Discord, AI chats, or anywhere else. If anyone asks for your session token for any reason, they are trying to scam you.

Session tokens appear to be long-lived (days to weeks). The bot will notify you on Slack if it expires.

Step 2 — Set Up Hyperliquid API

The bot needs an API wallet to place trades on your behalf.

1

Go to Hyperliquid

Open app.hyperliquid.xyz, connect your wallet, and make sure you have USDC deposited in your Perps wallet (not Spot — you can transfer in the Portfolio page).

2

Generate an API wallet

Click More → API in the top menu. Give it a name (e.g. "signal-bot") — important because unnamed wallets overwrite each other. Click Generate then Authorize API Wallet. Set validity to 180 days (maximum). Click Authorize and sign in MetaMask.

3

Copy your keys

You need two things:

  • Private Key — shown after generation (goes into HYPERLIQUID_API_PRIVATE_KEY)
  • Master Account Address — your main wallet address shown in the top-right dropdown (goes into HYPERLIQUID_MASTER_ACCOUNT_ADDRESS)
⚠️ The API wallet can place and cancel orders but cannot withdraw funds. Even in a worst-case scenario, your funds cannot be stolen via the API key — only bad positions could be opened, which you can close by revoking the key at app.hyperliquid.xyz.

Set a calendar reminder to regenerate the key before the 180-day expiry.

Step 4 — Set Up Slack Notifications Optional

Slack notifications tell you when the bot detects a signal, what trades it made, fill prices vs bar close prices, and when approval is needed.

  1. Go to api.slack.com/messaging/webhooks
  2. Click Create your Slack app → From scratch
  3. Name it "Signal Bot", pick your workspace
  4. Go to Incoming Webhooks → toggle ON
  5. Click Add New Webhook to Workspace, pick a channel
  6. Copy the webhook URL

If you skip this step the bot still runs — you'll just need to check the web dashboard manually.

Step 5 — Install & Deploy

1

Install Python 3.12

Download from python.org. During installation check "Add python.exe to PATH".

2

Download the bot code

Option A — using git:

git clone https://github.com/feartherealworld/PortfolioAutomation.git
cd trw

Option B — download ZIP from GitHub (green Code button → Download ZIP), extract it, open a terminal in the folder.

3

Install dependencies

pip install -r requirements.txt
4

Launch the setup manager

python manage.py

A browser page opens. Fill in:

  • Your TRW session token from Step 1
  • Your Hyperliquid API private key and master address from Step 2
  • Your Slack webhook URL from Step 4 (optional)
  • A username and password for your dashboard (recommended)

Click Save & Deploy. The manager handles everything — saving tokens, creating Modal secrets, and deploying the bot.

✓ After a successful deploy you'll see your dashboard URL. Bookmark it on your phone.

Maintenance

TRW Token Expired

If the bot stops reading signals or you get a Slack auth error notification:

  1. Open TRW in your browser, go to the signal channel
  2. F12 → Network → Fetch/XHR → reload → grab new x-session-token
  3. Run python manage.py → paste the new token → Save & Deploy

Hyperliquid API Key Expired

Keys expire after the validity period you set (max 180 days).

  1. Generate a new key at app.hyperliquid.xyz → More → API
  2. Run python manage.py → paste the new key → Save & Deploy

Updating the Bot

If you download an updated version of the code:

python manage.py

Click Save & Deploy to redeploy with your existing credentials.

Stopping the Bot

modal app stop signal-bot

Restarting

modal deploy modal_signal_bot.py

Security & Trust

You're about to enter API keys for your trading account into code. Here's what you should know.

The code only talks to 3 services — all yours

ServiceURLWhy
TRWeden.therealworld.agRead signals from the chat
Hyperliquidapi.hyperliquid.xyzRead positions and place trades
SlackYour own webhook URLSend YOU notifications

No other HTTP calls exist. No data goes to the author or any third party. Zero analytics, zero telemetry.

Verify it yourself

Search each Python file for requests.post and req.post. Every network call goes to one of the 3 URLs above. Or paste any file into Claude or ChatGPT and ask: "Does this code send my credentials anywhere other than TRW, Hyperliquid, and my Slack webhook?"

FAQ

Why perps instead of spot?

ETH, PAXG and XAUT don't have spot markets on Hyperliquid — they only exist as perps. Using 1x leverage perps gives identical economic exposure to holding spot. All positions use 1x cross leverage with no amplified risk.

What if the signal says "No change"?

The bot detects this and does nothing. It sends a Slack notification confirming "No change" so you know it's working.

What if the PAXG trade fails with a minimum order error?

Hyperliquid has a minimum order size of ~$10 for PAXG. At small account sizes (under ~$200) the 5.7% PAXG allocation falls below this. ETH and HYPE will still execute correctly. This resolves automatically as your account grows.

What if my internet goes down?

The bot runs in Modal's cloud, not on your computer. Your internet doesn't matter once deployed.

Can I stop the bot temporarily?

modal app stop signal-bot

Restart with modal deploy modal_signal_bot.py

How long does the TRW session token last?

Session tokens appear to last days to weeks. The bot sends a Slack alert when the token expires. Refreshing takes about 2 minutes.

What is the bar close equity toggle on the chart?

This shows what your portfolio value would be if every trade had executed at the exact bar close price (00:00 UTC). The gap between "Actual" and "Bar close" is your execution alpha loss — how much you paid in slippage and price movement in the minutes between signal detection and fill.

How do I export my equity history for analysis?

Click the Export CSV button on the dashboard. Downloads a CSV with columns date, actual_equity_usd, and barclose_equity_usd.

Is this financial advice?

No. This is a tool to automate a strategy you've chosen to follow. Always understand the signals before automating them. Use at your own risk.
